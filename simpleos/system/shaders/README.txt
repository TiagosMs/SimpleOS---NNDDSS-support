DraStic shaders from:
https://github.com/jdgleaver/drastic_ds_shaders

LCD1x, Sharp bilinear, zFast LCD, NDS Color, Natural Vision,
and the combined variants. Original .dfx / .dsd files.

Linux DraStic does not load these files itself. SimpleOS applies
the same filters from MENU -> VIDEO -> SHADER (live).
OFF is the default.

ports by jdgleaver).
